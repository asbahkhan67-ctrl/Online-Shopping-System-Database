# Online-Shopping-System-Database

The Online Shopping System manages:

--Customer information
--Product details
--Orders
--Payments
--Bill generation

Customers can place orders for products, and the system automatically calculates totals and stores payment records.

🧠Relationships:

One Customer → Many Orders
One Order → Many OrderDetails
One Product → Many OrderDetails
One Order → One Paymen

✅ Technologies Used
Microsoft SQL Server
SQL Queries
Stored Procedures
Triggers
Views
